Solmaris — an original open-world crime game built for the make.fun gta6-01 bounty ($1,666, top 100 paid). A sun-soaked coastal city you can explore on foot and by car: traffic, pedestrians, car stealing, a wanted system with police, a six-mission story chain, combat, shops, HUD + minimap, start and save — all original, all offline in a desktop browser.

- City: 5 districts on a real road graph (Marina Bay, Old Harbor, Palm Court, Sunvale, Coral Heights)
- Systems: on-foot + arcade driving, car stealing, traffic AI, pedestrians, wanted 0–5 stars, roadblocks, helicopter, missions, combat, economy, WebAudio sound
- Tech: 2.5D Canvas, Node 22, stdlib-only build (`main.ts`), no third-party engine

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/solmaris-out node main.ts
```

The game lands in `game/` with 4 screenshots and `dossier.json`.
